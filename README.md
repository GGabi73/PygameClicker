# PygameClicker
A pygame based clicker game that is highly modifiable and easy to configure.

The only thing that is needed to be configured are the "data/gamefiles" files, which lets you add producers, upgrades and simple achievements.

Currently you can't buy producers, upgrades or get achievement however they are in work.
