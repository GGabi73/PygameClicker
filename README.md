# PygameClicker
A pygame based clicker game that is highly modifiable and easy to configure.

The only thing that is needed to be configured are the "data/gamefiles" files, which will let you add producers, upgrades and simple achievements.

Currently you can't buy anything from the shop, enter the inventory or get achievements however they are in work.
