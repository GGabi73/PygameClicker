TAG {/} Name {/} Description {/} ForItem {/} Requirement {/} UpgradeType {/} Modifier {/} Cost;

Begin a value with i for intiger, s for string, b for bool and f for float
Everthing in an upgrade is seperated with " {/} ", each row must end with ";" and the file MUST end with an empty row
ForItem: ForItem is which building its for written in their tag: TOTAL, PLAYER, WRANGLER, BREEDER, THEIF, LAB, BROKER, JAVA, COOKIE
UpgradeType: Multiplier (multiply production), ForEachExclusive (multiply production for each other item owned), ForEachInclusive (multiply production for each item owned)
Modifier: adds on a value as a percentage / 100 (e.g a +100 percent boost (x2) is written with a modifier of 1)
